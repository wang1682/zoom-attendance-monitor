一键部署

三分钟从零到监控

Terminal Ubuntu / Debian 
# 一行命令安装
$ curl -fsSL https://raw.githubusercontent.com/your-org/zoom-attendance-monitor/v1.0.0-lite/install.sh | bash

# 30 秒后：
$ open http://localhost:8000
Docker 部署
docker compose up -d
  • ✓ 环境隔离
  • ✓ 一键升级
  • ✓ 跨平台兼容
systemd 部署
systemctl enable --now zoom-*
  • ✓ 生产性能
  • ✓ 自动重启
  • ✓ 日志集成

你需要准备的：

1.
Zoom App
创建 Server-to-Server OAuth App，添加 meeting scopes
2.
Telegram Bot
找 @BotFather 创建 Bot，获取 Token 和 Chat ID
3.
一台服务器
任何 Linux 虚拟机/VPS，512MB RAM 就够了
