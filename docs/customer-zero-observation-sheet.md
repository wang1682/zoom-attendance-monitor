# Customer Zero 观察记录表

## 使用说明

每轮测试用一份表。观察者记录用户每一步的完成时间和卡点，**不要主动帮助**，除非用户明确求助。

## 指标定义

| 指标 | 定义 |
|------|------|
| **TTFC** | Time To First Confusion — 用户第一次明显迷茫/停顿/问"这是什么意思"的时间点 |
| **TTFV** | Time To First Value — 用户看到第一条自己的参会记录的时间点 |
| **介入** | 用户主动求助或卡住超过 3 分钟，观察者需要介入的次数 |
| **FSR** | First-time Success Rate — 不求助的情况下成功完成该步骤的用户比例 |
| **UAR** | User Autonomy Rate — 全程无介入完成全部流程的用户比例 |
